# FAQ Section

## About the Project

This is a simple FAQ section created as part of my web development internship.

The project allows users to click on a question to expand or collapse its answer.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- 8 FAQ questions
- Expandable answers
- Collapsible answers
- Clickable question buttons
- Active state for opened questions
- Responsive design
- Simple and clean interface

## What I Learned

Through this project, I practiced JavaScript event handling, classList.toggle(), DOM manipulation, CSS styling, and responsive web design.

## Project Outcome

The FAQ section successfully displays questions and allows users to expand or collapse answers by clicking on the questions.
